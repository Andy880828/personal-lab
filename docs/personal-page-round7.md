## A. 會讓網站看起來壞掉的問題（P0）

1. **手機整頁可以橫向捲動**（已在正式站重現：390 寬時 scrollWidth 406）。
   - 原因：聯絡卡的 Email 用了 truncate（不換行），它的最小寬度把單欄 grid 撐開（`src/sections/Contact.tsx` 的 grid 與 EmailRow）。漢堡選單和「複製」鈕都被切掉。
   - 修法：grid 子項加 `min-w-0`；Email 不截斷，改成可斷行（`break-all`），字級隨寬度調整。
   - 測試缺口：現有的溢出 e2e 沒抓到。改成在 390、360 寬、捲到每一段之後，斷言 `scrollWidth === clientWidth`，並加 `isMobile` 的版本。
2. **社群分享圖還是第一輪的**：`public/og.jpg` 上寫「Full-stack & Data Engineer / Oceanographer」「全端與資料工程師」。跑 `npm run build && npm run og` 重產並 commit；之後職稱、首屏改動時要跟著重產（README 加一句）。
3. **作品導言寫「上面三個」，但三張卡在導言下面**（`src/sections/Projects.tsx`）。改成「最前面三個……其他作品在後面的清單」。篩選不是「全部」時，標題改「作品：{分類}」、導言改「{n} 個作品」，清單標題「更早的作品」改「已封存的作品」。
4. **科學註記有一句重複**（`src/content/science.ts:206`，第六輪替換時只換了一半）：「右邊的雙螺旋：右邊的雙螺旋分成五段……」→「右邊的雙螺旋分成五段，每段對應一組技能。」

## B. 首屏到關於的轉場、10 秒內的定位（P1）

1. **轉場殘影**：首屏是 150vh 的 sticky，pos 1.0–1.2 時按鈕列與座標行被推到頁頂，和 Logo 重疊；這時導覽還判定在首屏、背景透明；殘影下方到關於的標題之間空約 300 px。
   - 修法：首屏內容的透明度與位移綁 pos（0.75→1.0 淡出上移）；導覽背景改看首屏內容是否碰到導覽列，不看段落 id；收短首屏到關於之間的空白。
2. **10 秒內看不到他做什麼**：首屏只有名字、職稱、按鈕。
   - 修法：職稱下加一行站上現有的定位句（例如「把雜亂的資料整理成別人查得到、驗得了的系統」）。另一個選項是首屏下緣加一條很淡的「代表作」列（FORGE · Trim2Sort · syssec），點了捲到該卡；第六輪刻意沒加，這次列為選項，由站主決定。
3. **定位前後打架**：關於的標題「從溪流裡的 DNA，到伺服器裡的漏洞」把終點講成資安；自我介紹說「現在做三件事」，技能標題說「五個方向」。
   - 修法：關於標題改成和職稱同軸（例如「從一條溪的 DNA，到一整套資料流程」）；自我介紹不寫「三件事」；技能標題改「五個方向的技能」，不用冒號式。標題措辭請站主挑。
4. **手機首屏按鈕**：「聯絡我」單獨掉到第二行。手機上改成兩顆主按鈕一行，「聯絡我」放到座標行旁當文字連結。
5. **入水時 CTA 對比**：pos ≈ 0.6 時水線劃過按鈕列，「直接看作品」短暫看不清。按鈕列加淡底色或陰影。

## C. 作品段（P1／P2）

1. **並排的兩張精選卡不等高**（差約 120 px，連結列不對齊）。原因是 `src/components/TiltCard.tsx` 外層的 perspective div 沒有 `h-full`。
2. **FORGE 的截圖選錯畫面**：現在是「活動規則」文字頁，縮圖上讀不出內容。請站主補一張排行榜或計分畫面〔待確認〕，`object-position` 對到排名表。
3. **終端機封面**：右上的彩色模糊光暈像污漬，而且違反 DESIGN.md「不用零位移的彩色光暈」，拿掉；橫向捲動沒有提示，加右緣漸隱遮罩；syssec 封面「checks 51: 21 pass, 9 fail」加起來對不上，換成實際輸出〔待確認〕。
4. **「其他作品」清單**：中文副名斷在詞中間（「本地轉錄與講／者辨識」），副名整段不斷行或換到第二行；「原始碼／原始碼未公開」欄對齊，未公開用鎖頭圖示，和卡片一致。
5. **Trim2Sort 的亮點順序**：非精選時只顯示前兩條，現在顯示的是「CustomTkinter 圖形介面」，有用的「輸出 Excel」被切掉。把結果放前面、技術放最後；中文名「DNA 序列分析 GUI」→「eDNA 序列分析工具（圖形介面）」。「過濾序列」的實際意思〔待確認〕。
6. **stock-analysis-app**：摘要重複中文名、highlights 重述摘要、封面不是真的指令輸出（違反「封面放 README 裡真的會出現的指令」）。摘要改寫；highlights 與封面等站主補實際功能〔待確認〕，沒有就不放封面。
7. **FORGE 亮點**：「男女分組排名……」和摘要同一句。等成果數字〔待確認〕；在那之前刪掉這條，讓測試與部署往前補位。

## D. 3D 與內容的關係（P1／P2）

1. **礁區修過頭**：現在壓在關於第二、三段內文與「看完整履歷」下面，同色的連結疊在同色的礁上，對比下降。礁往左下推（x ≈ −14、y 偏移 ≈ −10），只露在內文欄左下角；加一條 e2e：關於內文框內的 canvas 亮度上限。
2. **海床的熱泉、管蟲、大王具足蟲都在聯絡卡後面**：熱泉移到卡片與左欄之間的縫或卡片右側之外，具足蟲移到卡片下方的空地。
3. **桌機聯絡段先讀到興趣**：lg 以上也把聯絡卡放在左欄（閱讀順序第一），興趣與照片放右欄。
4. **拼貼照**：白底旋轉的拼貼和聲納風格不搭，裡面還有遊戲官方插圖與 Logo，頁尾卻寫「照片版權所有」。拿掉官方圖；照片統一調暗、去白框，或改成同尺寸格狀。素材替換需要站主〔待確認〕。
5. **tier 0 的海床是純黑**：加一張靜態 SVG 等深線當背景，讓沒有 3D 的人也有抵達感。

## E. 用語第二輪（P0–P2）

**規則補齊（第六輪沒套全的）**

- FORGE 摘要「InBody 數據」→「InBody 量測結果」。
- 技能「可被程式呼叫的 CLI（JSON 輸出、穩定錯誤碼）」→「讓其他程式直接呼叫的指令列工具（固定格式的 JSON 輸出與錯誤碼）」。
- scout「零依賴 Go 單一執行檔，所有指令都有固定的 JSON envelope」→「Go 寫的單一執行檔，不需另外安裝套件；每個指令都輸出固定格式的 JSON，方便其他程式接手」。
- 深度千分位：科學註記標題（1,000–4,000 m、4,000 m）、指令列 help（0–4,000 m）。
- og:description 的「Agent 工具」→「Agent 應用」，並把主詞寫清楚。

**新的問題**

- syssec 摘要的動作順序反了：先比對已裝套件、再找已知漏洞。中文名「主機安全稽核 CLI」→「主機安全稽核工具（CLI）」。
- local-transcribe「影片或錄音進、標好講者的逐字稿出」是翻譯腔，「自己的 GPU」不清楚是誰的 →「把影片或錄音轉成標好講者的逐字稿；轉錄與講者辨識都在本機的顯示卡上執行，音訊不會上傳。」
- homelab 的「閘道」「虛擬金鑰」招募者讀不懂；「能重算」→「可重現」；技能「特徵整理」→「特徵工程」、「權限邊界」改成具體說法。
- 重複：技能 Agent 的摘要與亮點、andy-claude-kit 的摘要與亮點各講了兩次同一件事。
- 數字寫法統一用阿拉伯數字（6 個），中文句子裡的英文名詞不加複數 s。
- 經歷：資展的課程被歸在「學歷」，新增 kind「進修」；「專案」標籤與「個人專案」重複；「打工度假」在美國其實是暑期打工旅遊（Work and Travel）〔待確認〕；「海洋科學系研究所」→「碩士班」〔待確認〕。
- 「減少動態：開」是雙重否定，改「動態效果：開／關」，和 `motion on|off` 同一套。
- 首屏「按 / 開指令列」的斜線夾在中文裡像分隔線，用 `<kbd>` 或「按「/」」。

**指令列整理**

- 訊息格式統一：指令開頭的錯誤或狀態用 `指令: 說明`（半形冒號加空格），欄位標籤用中文加全形冒號。
- `cat` 的輸出：`tools:`／`tags:` 改「工具：」「技術：」，中文後面接全形括號。
- `goto` 不帶參數時輸出有多餘空格、一次列 14 個別名，改成只列 6 個段落名。
- `tier` 的輸出統一寫「3D 等級 N」；`ascii on` 在不支援的等級下不要先說 on；`dive` 不要印兩次深度。
- `contact` 的 Facebook 網址太長、爆出面板，顯示短的連結文字。
- 海底名稱三套並存（段落刻度「海床」、`here` 在 3,800 m 說「深層帶」、`dive 4000` 說「深淵帶」）：統一成「海床（深層帶底部）」，深淵帶只出現在 4,000 m 以下的分層資料。

**lint**

- 禁用「數據」，用白名單放行台郡的正式職稱。

## F. 細節、可及性、測試缺口（P2／P3）

- 技能段在 1024 寬時，兩欄條列把詞斷開（「特徵整／理」），lg 改單欄、xl 再兩欄；五顆分頁鈕在 lg 以上排一行。
- 關於標題在 1024 寬斷在詞中間，用 `<wbr>` 或逐詞不斷行控制斷點。
- 經歷每列的層帶背景拉滿 1,218 px、內容只有兩行，背景收到內容寬；等台郡的成果補上後，主列在 lg 以上改兩欄。
- 頁尾的「謝謝你潛到最底。」被指令列按鈕壓到，頁尾在 md 以上加左內距。
- 指令列按鈕在 Tab 順序裡排在首屏按鈕之前：把 Console 移到 main 之後。
- SplitHeading 動畫期間會複製出同 id 的空 span，聯絡段的區域名稱一度變成空字串：id 放在 h2 上。
- 複製鈕補 `aria-label="複製 Email"`；連結的 sr-only 文字統一成「（名稱，GitHub）」；截圖 alt 寫內容〔待確認〕。
- index.html 補 `og:url`、`og:site_name`、`og:image:alt`、`twitter:title`。
- README「所有文案都在 src/content/」不正確；版權說法全站三種，統一。
- 技能面板頂端三層等寬小字（英文名、工具數、DNA 序列）搶標題，只留一層；大頭照白底太亮，壓暗或縮小。
